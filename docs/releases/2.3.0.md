BitcoinPrice 2.3.0 ergänzt die Textsprache und die persönliche Anzeige, ohne bestehende Plugin-Daten zurückzusetzen. Benötigt Paper 26.2 und Java 25.

- Deutsch/Englisch mit `/btc language de|en|AUTO|DEFAULT`; optional serverweit automatische Erkennung über `/btc global language AUTO`. Persönlich gewählte Sprachen haben Vorrang. Das Zahlenformat bleibt separat unter `/btc locale`.
- Actionbar-Inhalte `price`, `change` und `full` über `/btc display actionbar content`. Zeitmodus und Intervall bleiben unabhängig; auch kurze Anzeigen kennzeichnen veraltete oder zeitlich unbekannte Kurse.
- `/btc status` erklärt Ratenlimits, Timeouts, Verbindungs-/HTTP-Fehler, ungültige Antworten, veraltete Anbieterdaten sowie API-/Refresh-Wartezeiten ohne zusätzliche Abfrage.
- Bestehende Spielerprofile und eigene Nachrichtenvorlagen bleiben kompatibel; OPs können die neuen persönlichen Einstellungen auch für offline gespeicherte Spieler setzen.

Installation: Server stoppen, genau eine BitcoinPrice-JAR durch `BitcoinPrice-2.3.0.jar` ersetzen und vollständig neu starten. `plugins/BitcoinPrice` und die Welt behalten. Kein `/reload`.

Validierung: Maven `clean verify`, 67 Tests erfolgreich, keine Fehler oder übersprungenen Tests. Der zusätzliche Paper-Integrationstest wurde nicht ausgeführt.
